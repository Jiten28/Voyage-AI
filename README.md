# 🌍 Overview

AI-powered travel planner that generates personalized itineraries, budget breakdowns, hotel recommendations, weather insights, and AI-generated destination visuals using Google Gemini, React, and TypeScript.

---

# ✨ Features

- 🤖 AI-powered personalized travel itinerary generation
- 🗓️ Day-wise trip planning
- 💰 Budget estimation
- 🏨 Hotel recommendations
- 🍽️ Restaurant suggestions
- 📍 Tourist attraction recommendations
- 🌤️ Weather forecasting
- 🖼️ AI-generated destination images
- 🌎 Interactive travel experience
- 🌙 Dark & Light Theme
- 💱 Currency conversion
- 📱 Responsive modern UI

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/Jiten28/Voyage-AI.git
```

Navigate into the project

```bash
cd Voyage-AI
```

Install dependencies

```bash
npm install
```

Create a `.env.local`

```env
GEMINI_API_KEY=YOUR_API_KEY
```

Run locally

```bash
npm run dev
```
